# CTO Technical Authority — Domínios de Conhecimento

## Domínios de Engenharia (Todos)

### 1. Software Engineering
- Arquitetura de sistemas (monolítico, microsserviços, serverless)
- Design patterns e anti-patterns
- Princípios SOLID, DRY, KISS, YAGNI
- Metodologias ágeis e práticas de desenvolvimento
- Versionamento e gestão de código (Git)

### 2. Frontend
- Frameworks: React, Vue, Angular, Svelte
- HTML5, CSS3, JavaScript/TypeScript
- Design systems e componentização
- Performance e acessibilidade (WCAG)
- State management e rotas

### 3. Backend
- Linguagens: Python, Node.js, Go, Rust, Java
- Frameworks: FastAPI, Express, NestJS, Spring
- APIs: REST, GraphQL, gRPC, WebSockets
- Autenticação: JWT, OAuth2, OIDC
- Padrões: Clean Architecture, Hexagonal, DDD

### 4. Infraestrutura e DevOps
- Cloud: Oracle Cloud, AWS, Azure, GCP
- Containers: Docker, Podman, Kubernetes
- CI/CD: GitHub Actions, GitLab CI, Jenkins
- IaC: Terraform, Ansible, Pulumi
- Monitoramento: Prometheus, Grafana, ELK

### 5. Segurança
- OWASP Top 10 e mitigações
- Criptografia: AES, RSA, TLS, hashing
- Autenticação e autorização
- LGPD, GDPR, regulação de dados
- Segurança de APIs e microserviços

### 6. Dados
- Bancos relacionais: PostgreSQL, MySQL, SQLite
- Bancos NoSQL: MongoDB, Redis, DynamoDB
- Modelagem: normalização, DDD, data lakes
- ETL/ELT e pipelines de dados
- Qualidade de dados e governança

### 7. IA e Machine Learning
- LLMs: OpenAI, Anthropic, modelos open-source
- Agentes IA: design, orquestração, evaluate
- RAG: retrieval-augmented generation
- Embeddings e vector databases
- Prompt engineering e fine-tuning

### 8. Qualidade e Testes
- Testes: unitário, integração, E2E, performance
- TDD, BDD, testes de carga
- Code review e pair programming
- Métricas de qualidade: defeitos, cobertura, complexidade

## Domínios de Verificação

### 9. Verificação de Fontes
- Fontes confiáveis: docs oficiais, paper, repos verificados
- Cross-reference: múltiplas fontes para validação
- Atualidade: verificar data de publicação e relevância
- Confiabilidade: avaliar credibilidade da fonte

### 10. Fact-checking Técnico
- Especificações: verificar contra documentação oficial
- Compatibilidade: validar informações de integração
- Performance: confirmar claims com benchmarks
- Segurança: verificar CVEs e advisories

## Conhecimento Não-Fundamental (Delegar)
- Estratégia de negócio e análise de mercado (CEO)
- Gestão financeira e modelagem (CFO quando existir)
- Marketing e comunicação (divisão comercial)
- Recursos humanos e gestão de pessoas
- Assuntos legais e regulatórios (humano)

## Atualização de Conhecimento
- Contínuo: absorção via revisões e web-research
- Semanal: revisão de CVEs e advisories de segurança
- Mensal: avaliação de novas tecnologias e tendências
- Trimestral: revisão completa de padrões e best practices
