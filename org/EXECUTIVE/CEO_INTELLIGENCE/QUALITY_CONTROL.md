# CEO Intelligence Agent — Controle de Qualidade

## Critérios de Qualidade para Saídas do CEO

### 1. Executive Brief
- **Tamanho:** Máximo 1 página (500 palavras)
- **Estrutura:** Contexto → Decisão → Opções → Recomendação → Riscos
- **Dados:** Pelo menos 2 fontes de dados para cada afirmação-chave
- **Ação:** Recomendação clara e inequívoca em cada brief
- **Tom:** Profissional, conciso, orientado a decisão

### 2. Strategic Report
- **Estrutura:** Sumário → Contexto → Análise → Opções → Recomendação → Anexos
- **Dados:** Dados quantitativos quando disponíveis, qualitativos quando não
- **Análise:** Pelo menos 3 opções avaliadas com prós/contras
- **Riscos:** Cada opção com matriz de risco associada
- **Acompanhamento:** Métricas de sucesso definidas para recomendação

### 3. Decision Record
- **Campos obrigatórios:** Data, contexto, opções consideradas, decisão tomada, justificativa, responsável, data de revisão
- **Rastreabilidade:** Cada decisão rastreada a um objetivo estratégico
- **Auditoria:** Registro imutável após confirmação

### 4. Opportunity Card
- **Scoring:** Impacto × Probabilidade ÷ Custo (escala 1-10)
- **Dados:** Fonte da oportunidade, dados de suporte, assumptions
- **Classificação:** Quick Win / Strategic / Long-term / Deprioritize
- **Próximo passo:** Ação recomendada específica

## Processo de Revisão

### Auto-avaliação (CEO)
1. Dados estão atualizados (menos de 30 dias)?
2. Análise considera pelo menos 3 perspectivas?
3. Recomendação é clara e acionável?
4. Riscos estão identificados e mitigações propostas?
5. Formato segue o padrão definido?

### Revisão Técnica (CTO)
- Conteúdo técnico validado por CTO antes de aprovação final
- Dados técnicos verificados contra fontes confiáveis
- Viabilidade técnica confirmada

### Aprovação Final
- CEO assina off apenas após revisão técnica aprovada
- Registro de aprovação com timestamp e responsável

## Métricas de Qualidade
- **Acurácia:** > 95% das afirmações verificáveis
- **Completude:** 100% dos campos obrigatórios preenchidos
- **Tempo:** Prazos de entrega cumpridos em > 90% dos casos
- **Satisfação:** Proprietário humano avalia qualidade periodicamente
