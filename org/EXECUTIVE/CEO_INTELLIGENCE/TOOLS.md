# CEO Intelligence Agent — Ferramentas

## Ferramentas Primárias

### web-research
- **Uso:** Pesquisa de mercado, tendências, dados de concorrência
- **Capacidades:** Busca web, extração de conteúdo, análise de fontes
- **Limitações:** Dados podem estar defasados; verificar sempre a fonte
- **Quando usar:** Sempre que dados atuais são necessários para decisão

### data-analysis
- **Uso:** Análise de dados quantitativos e qualitativos
- **Capacidades:** Processamento de dados tabulares, cálculos, estatísticas
- **Limitações:** Dados de entrada devem ser fornecidos ou coletados
- **Quando usar:** Para scoring de oportunidades, análise de ROI, KPIs

### opportunity-scoring
- **Uso:** Sistema padronizado de avaliação de oportunidades
- **Fórmula:** Impacto (1-10) × Probabilidade (1-10) ÷ Custo (1-10)
- **Classificação:**
  - Score > 25: **Quick Win** — Executar imediatamente
  - Score 15-25: **Strategic** — Planejar e executar com cuidado
  - Score 8-15: **Long-term** — Monitorar e aguardar
  - Score < 8: **Deprioritize** — Registrar e revisitar trimestralmente
- **Quando usar:** Para toda oportunidade identificada

## Ferramentas de Comunicação

### executive-briefing-tool
- **Uso:** Formatação de briefings executivos padronizados
- **Formato:** Contexto → Decisão → Opções → Recomendação → Riscos
- **Quando usar:** Para qualquer solicitação de decisão do proprietário

### escalation-notifier
- **Uso:** Notificação estruturada para escalamento
- **Quando usar:** Quando decisão exige aprovação humana

## Ferramentas de Acompanhamento

### decision-tracker
- **Uso:** Registro e acompanhamento de decisões
- **Capacidades:** CRUD de decisões, busca por data/tipo/status
- **Quando usar:** Sempre que uma decisão é tomada

### kpi-dashboard
- **Uso:** Visualização de métricas estratégicas
- **Métricas:**
  - Pipeline de oportunidades (total, por classificação)
  - Taxa de conversão de oportunidades
  - Decisões pendentes vs. tomadas
  - Ações em execução vs. concluídas
  - Tempo médio de decisão
- **Quando usar:** Daily review e relatórios semanais

## Restrições de Uso
- NÃO usar ferramentas para acessar dados financeiros sensíveis sem autorização
- NÃO usar web-research para autopromoção ou conteúdo não relacionado
- Todas as ferramentas operam dentro dos limites de permissão do LEVEL 4
- Logs de uso das ferramentas são mantidos para auditoria
