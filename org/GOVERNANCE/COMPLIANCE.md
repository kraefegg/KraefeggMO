## Checklist de Conformidade

### LGPD (Lei Geral de Proteção de Dados)
- [ ] Base legal identificada para cada tratamento de dados pessoais
- [ ] Consentimento obtido quando aplicável
- [ ] Direitos do titular assegurados (acesso, correção, exclusão, portabilidade)
- [ ] Encarregado de dados (DPO) designado
- [ ] Relatório de Impacto à Proteção de Dados (RIPD) para operações de alto risco
- [ ] Dados pessoais criptografados em trânsito e repouso
- [ ] Política de retenção e exclusão de dados implementada
- [ ] Registro de operações de tratamento mantido

### Marco Civil da Internet
- [ ] Liberdade de expressão respeitada
- [ ] Privacidade e proteção de dados preservadas
- [ ] Neutralidade da rede respeitada
- [ ] Responsabilidade adequada dos intermediários

### Normas Profissionais
- [ ] Conselho de classe aplicável (CAU, CREA, etc.) — quando aplicável
- [ ] Registro profissional válido
- [ ] Seguro de responsabilidade civil — quando aplicável
- [ ] Declaração de conflito de interesse

### Compliance Setorial (conforme atividade)
- [ ] ANTAQ: Conformidade para operações aquaviárias
- [ ] ANP: Conformidade para operações de petróleo/gás
- [ ] IBAMA/CONAMA: Conformidade ambiental
- [ ] ANTAQ/ISPS: Segurança portuária
- [ ] ANM: Conformidade para operações de mineração

## Responsabilidade Profissional

### Princípios
- Diligência: executar com competência e zelo
- Imparcialidade: sem conflito de interesse
- Sigilo: respeitar confidencialidade
- Transparência: comunicação clara e honesta
- Integridade: agir eticamente em todas as situações

### Conflito de Interesse
- Declarar qualquer conflito potencial antes de iniciar tarefa
- Se conflito identificado: agente se declara e é substituído
- Registro de declarações mantido em governance

## Penalidades e Consequências

### Não Conformidade Interna
- **Leve:** Advertência + treinamento corretivo
- **Média:** Suspensão temporária de permissões
- **Grave:** Rebaixamento de nível + revisão de acesso
- **Gravíssima:** Rescisão / remoção do sistema

### Não Conformidade Regulatória
- Multas conforme legislação aplicável
- Responsabilização civil e/ou criminal
- Dano reputacional
- Perda de credenciais/autorizações
