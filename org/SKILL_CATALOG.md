## Como Usar Skills

1. **Identificação:** Consultar `AGENT_SKILL_MATRIX.md` para saber quais skills cada agente possui
2. **Ativação:** Skills são ativadas automaticamente pelo workflow ou por solicitação do agente
3. **Compartilhamento:** Skills SHARED podem ser usadas por qualquer agente
4. **Especialização:** Skills profissionais são restritas aos agentes da categoria correspondente
5. **Versão:** Toda skill está em versão 1.0; atualizações seguem versionamento semver
